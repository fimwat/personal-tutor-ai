# Constraints
- Target learner: neurotypical ~7yo, dyslexia-FRIENDLY design (safe for dyslexic learners), NOT a Tier-3 intervention.
- OG-aligned reading/spelling curriculum for MCG.
- Asset intended to be COMMERCIALLY SELLABLE.
- No auth/Google Cloud OAuth setup; prefer Composio/MCP or simple stub.
- Self-contained static web app preferred; Electron/React okay for premium.
- Assessment UI rules (firm): randomise choices; audio-recognition shows NO visual cue; phoneme tasks need real engine (meSpeak/eSpeak WASM or clips), never word-TTS; narration may use female voice but NOT for isolated phonemes.
- Student-interactive + auto-scored, not parent-manual.
